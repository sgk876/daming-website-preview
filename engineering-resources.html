TECHNICAL FAQ

Find the Question Behind the Requirement.

12 questions

Can we start without a drawing?

Yes. Tell us about the equipment, intended functions and any known size or host constraints. We help identify missing decisions and agree the next design work.

Read the related guide →
What information is needed for a useful recommendation?

Application, user functions, available space, existing parts and main priorities are a useful start. Approximate information is welcome; confirmed facts and open questions should remain distinct.

Read the related guide →
How should we define glove or wet-hand operation?

Describe the glove type, moisture scenario, intended actions and expected behavior. These conditions need to be agreed for the configuration and sample checks, rather than treated as an unconditional feature.

Glove & wet-touch FAQ →Read the related guide →
What if touch behaves differently after installation?

Record the equipment configuration, power source, host, cables, environment and steps that reproduce the issue. The component and equipment teams can then agree what to review and test.

Read the related guide →
Can keys, graphics and a display window share a panel?

We can review them as a coordinated layout. Cover construction, sensing arrangement, window, mounting and controller connection are confirmed for the project.

Read the related guide →
Is glass, PC or PMMA always the better choice?

No single material name answers the whole design question. Review the actual material grade, construction, printing, cleaning, exposure and installation requirements.

Read the related guide →
Can we supply the LCD for bonding?

Customer-supplied components can be evaluated. Model, specification, incoming condition, representative samples and responsibility for the supplied parts need agreement.

Read the related guide →
Should every display use optical bonding?

The route depends on component suitability, optical and mechanical goals, handling, service and project constraints. Compare the complete constructions before selection.

Read the related guide →
Does an HDMI input guarantee compatibility with any LCD?

The agreed configuration must also account for the selected panel, display-side connection, driver setup, power, pinout and cables. HDMI input alone is not the complete kit specification.

Read the related guide →
Can the supply include a board and matching cables?

These accessories can be reviewed as part of a touch display assembly. The exact component list, connection references and functional checks are agreed for the project.

Read the related guide →
Are drawings, samples and development free?

Scope, deliverables, quantities, costs and schedules are agreed for each project. This prototype does not promise free design work or samples.

Read the related guide →
Where can we download approved specifications?

This preview offers planning checklists only. Model-specific specifications, drawings and verified reports will be listed after technical review and permission for public use.
