# DaMing public website

Public site for https://pcaptouch.com with live inquiry delivery through FormSubmit to sgk@touch-displays.com. First-time recipient activation may be required. Printed certificate information does not independently establish current registration status. Unconfirmed product figures and customer case claims are not fabricated.

Repository contents match the live pcaptouch.com package (Cloudflare Pages deployment b3805061). `DAMING_SITE.base` is `/`. `robots.txt` allows crawling and lists https://pcaptouch.com/sitemap.xml. Published pages use `index,follow`. The live package still marks `404.html`, `company`, `applications/directory`, and `support/faq` as `noindex`.
